# Contribuir

Gracias por ayudar a mejorar Presenta PDF.

1. Abre un issue para explicar un fallo o una mejora, indicando plataforma y formato de URL (oculta datos privados).
2. Crea una rama de cambios, ejecuta `npm test` y `npm run check`.
3. Envía un pull request con capturas de antes y después si cambiaste la interfaz.
4. No envíes presentaciones ajenas ni contenido con derechos de autor al repositorio.

Las capturas de Google Slides y Genially cambian con las actualizaciones de sus visores: documenta los casos reproducibles.
